
# 🍕 Pizza Sales Analysis Using SQL

## Overview

This project focuses on analyzing pizza sales data using SQL to identify business trends, evaluate sales performance, and understand customer ordering behavior.

The analysis covers key performance indicators (KPIs), monthly and daily order trends, revenue contribution by pizza category and size, and top- and bottom-performing pizzas. SQL queries are used to transform raw sales data into meaningful business insights that can support data-driven decision-making.

## Objectives

- Calculate key sales performance indicators (KPIs).
- Analyze total revenue, total orders, and pizzas sold.
- Calculate average order value and average pizzas per order.
- Identify monthly revenue trends and daily order patterns.
- Analyze revenue contribution by pizza category and size.
- Compare pizza quantities sold across sizes and categories.
- Identify the top 5 and bottom 5 pizzas by revenue.
- Identify the top 5 and bottom 5 pizzas by orders and quantity sold.

## Dataset

The project uses a pizza sales dataset containing order-level and pizza-level sales information.

**Database:** SQL  
**Table Name:** `PIZZA_SALES`

### Dataset Columns Used

| Column | Description |
|---|---|
| `ORDER_ID` | Identifier for each customer order |
| `ORDER_DATE` | Date the order was placed |
| `TOTAL_PRICE` | Revenue generated by the pizza sales record |
| `QUANTITY` | Number of pizzas sold |
| `PIZZA_CATEGORY` | Category of the pizza |
| `PIZZA_SIZE` | Size of the pizza |
| `PIZZA_NAME` | Name of the pizza |

*Note: These columns are based on the SQL queries used in this project. Additional columns may exist in the original dataset.*

## Business Problems and Solutions

### 1. Key Performance Indicators (KPIs)

#### 1.1 Total Revenue

**Objective:** Calculate the total revenue generated from pizza sales.

```sql
SELECT
    SUM(TOTAL_PRICE) AS TOTAL_REVENUE
FROM PIZZA_SALES;
```

#### 1.2 Total Orders

**Objective:** Calculate the total number of distinct customer orders.

```sql
SELECT
    COUNT(DISTINCT ORDER_ID) AS TOTAL_ORDERS
FROM PIZZA_SALES;
```

#### 1.3 Average Order Value

**Objective:** Calculate the average revenue generated per order.

```sql
SELECT
    CAST(
        SUM(TOTAL_PRICE) * 1.0
        / NULLIF(COUNT(DISTINCT ORDER_ID), 0)
        AS DECIMAL(10,2)
    ) AS AVG_ORDER_VALUE
FROM PIZZA_SALES;
```

#### 1.4 Total Pizzas Sold

**Objective:** Calculate the total quantity of pizzas sold.

```sql
SELECT
    SUM(QUANTITY) AS TOTAL_PIZZAS_SOLD
FROM PIZZA_SALES;
```

#### 1.5 Average Pizzas Per Order

**Objective:** Determine the average number of pizzas sold per order.

```sql
SELECT
    CAST(
        SUM(QUANTITY) * 1.0
        / NULLIF(COUNT(DISTINCT ORDER_ID), 0)
        AS DECIMAL(10,2)
    ) AS AVG_PIZZAS_PER_ORDER
FROM PIZZA_SALES;
```

### 2. Sales Trend Analysis

#### 2.1 Monthly Revenue Trend

**Objective:** Analyze revenue generated during each month.

```sql
SELECT
    EXTRACT(MONTH FROM ORDER_DATE) AS MONTH_NUMBER,
    TO_CHAR(ORDER_DATE, 'Month') AS MONTH,
    SUM(TOTAL_PRICE) AS TOTAL_REVENUE
FROM PIZZA_SALES
GROUP BY
    EXTRACT(MONTH FROM ORDER_DATE),
    TO_CHAR(ORDER_DATE, 'Month')
ORDER BY MONTH_NUMBER;
```

#### 2.2 Daily Order Trend

**Objective:** Understand which days of the week generate the most orders.

```sql
SELECT
    EXTRACT(ISODOW FROM ORDER_DATE) AS DAY_NUMBER,
    TO_CHAR(ORDER_DATE, 'FMDay') AS DAY,
    COUNT(DISTINCT ORDER_ID) AS TOTAL_ORDERS
FROM PIZZA_SALES
GROUP BY
    EXTRACT(ISODOW FROM ORDER_DATE),
    TO_CHAR(ORDER_DATE, 'FMDay')
ORDER BY DAY_NUMBER;
```

### 3. Revenue Contribution Analysis

#### 3.1 Percentage of Sales by Pizza Category

**Objective:** Calculate total revenue and each category's percentage contribution to overall revenue.

```sql
SELECT
    PIZZA_CATEGORY,
    SUM(TOTAL_PRICE) AS TOTAL_REVENUE,
    ROUND(
        SUM(TOTAL_PRICE) * 100.0
        / NULLIF((SELECT SUM(TOTAL_PRICE) FROM PIZZA_SALES), 0),
        2
    ) AS REVENUE_PERCENTAGE
FROM PIZZA_SALES
GROUP BY PIZZA_CATEGORY
ORDER BY TOTAL_REVENUE DESC;
```

#### 3.2 Percentage of Sales by Pizza Size

**Objective:** Identify the revenue contribution of each pizza size.

```sql
SELECT
    PIZZA_SIZE,
    SUM(TOTAL_PRICE) AS TOTAL_REVENUE,
    ROUND(
        SUM(TOTAL_PRICE) * 100.0
        / NULLIF((SELECT SUM(TOTAL_PRICE) FROM PIZZA_SALES), 0),
        2
    ) AS REVENUE_PERCENTAGE
FROM PIZZA_SALES
GROUP BY PIZZA_SIZE
ORDER BY TOTAL_REVENUE DESC;
```

### 4. Pizza Quantity Analysis

### 5. Top and Bottom Pizza Performance Analysis

#### 5.1 Top 5 Pizzas by Revenue

**Objective:** Identify the five pizzas generating the highest revenue.

```sql
SELECT
    PIZZA_NAME,
    SUM(TOTAL_PRICE) AS TOTAL_REVENUE
FROM PIZZA_SALES
GROUP BY PIZZA_NAME
ORDER BY TOTAL_REVENUE DESC
LIMIT 5;
```

#### 5.2 Bottom 5 Pizzas by Revenue

**Objective:** Identify the five pizzas generating the lowest revenue.

```sql

GROUP BY PIZZA_NAME
ORDER BY TOTAL_REVENUE ASC

```
